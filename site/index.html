What the county number means

Each number is the number of Sep–May days the selected threshold was reached. The coldest selected IEM observation in the county represents that day. Counties with no station use the nearest regional station and are flagged when clicked.

Frost is a temperature-support screen; frost itself is not directly observed by ASOS/AWOS.
