HIT / MISS—
Primary verification queries all available IEM airport ASOS/AWOS/METAR sites across the selected CWA during the exact VTEC valid period, merging the static catalog with current IEM state-network metadata. For temperature hazards it uses the colder of the instantaneous temperature and any METAR-reported 6-hour minimum, preventing valid lows from being missed. IEM station metadata supplies plotted coordinates; RWIS and other supplemental networks add additional surface coverage when available. All usable networks use the same verification colors: green = threshold hit inside the issued hazard, yellow = issued hazard but threshold not hit, and red = threshold hit outside the issued hazard. COOP uses a 24-hour low; RWIS/USCRN/DCP use the exact VTEC window when available. DCP sites are included only when an air-temperature (TA) series is available. Synoptic Mesonet/CWOP stations are also included; for Frost Advisory they use station T/Td/wind plus a nearby-in-time METAR sky-cover proxy when available. Stations across the entire CWA are checked. All available sites are drawn for auditing. Stations that neither meet the criterion nor fall inside the selected hazard are shown neutrally in gray with only their observed value; criterion hits outside the selected hazard remain red. Frost Advisory verification is driven only by observed-condition PotFrost: PF ≥40 verifies (green inside the advisory / red outside), while PF <40 inside the advisory is yellow. Stations without enough T/Td/wind or a reasonably close sky observation remain gray and do not count as a verification result. A station's own sky is preferred; otherwise the closest usable sky observation in the event window is used.

What the county number means

Each number is the number of Sep–May days the selected threshold was reached. The coldest selected IEM observation in the county represents that day. Counties with no station use the nearest regional station and are flagged when clicked.

Frost Advisory verification uses the observed-condition PotFrost method from METAR T/Td, wind and cloud cover. Patchy (20) does not verify; Areas (40) or Widespread (70) does.
